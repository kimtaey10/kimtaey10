# 김태윤

### 컴퓨터과학 · 정보보안 · 정보관리

컴퓨터 시스템과 정보의 구조를 이해하고,
안전하고 신뢰할 수 있는 정보 시스템을 설계하는 것에 관심이 있습니다.

현재 컴퓨터과학을 기반으로 정보보안과 정보관리를 함께 공부하며
시스템, 네트워크, 데이터, 보안의 관계를 폭넓게 학습하고 있습니다.

## 자기소개

안녕하세요. 컴퓨터과학과 정보보안을 공부하고 있는 학생 김태윤입니다.

컴퓨터 시스템이 어떻게 동작하는지 이해하는 것에서 시작하여
운영체제, 컴퓨터 네트워크, 데이터베이스, 정보보안 등의 분야를 학습하고 있습니다.

특히 정보가 생성되고, 저장되고, 처리되며, 전달되는 전체 과정에 관심이 있습니다.

이를 바탕으로

> **컴퓨터 시스템 → 정보 → 보안 → 관리**

의 관점에서 기술을 이해하고자 합니다.

새로운 기술을 단순히 사용하는 것보다
그 기술이 어떤 원리로 동작하는지 이해하고,
실제 시스템에 적용하는 과정을 중요하게 생각합니다.

 ## 개발 및 학습 방향

 제가 기술을 학습할 때 중요하게 생각하는 것은\
 단순히 구현 결과를 얻는 것이 아니라 **원리와 구조를 이해하는 것**입니다.

 하나의 시스템을 공부하거나 개발할 때

```
요구사항 분석
      ↓
시스템 구조 이해
      ↓
데이터 설계
      ↓
기능 구현
      ↓
보안 요소 분석
      ↓
테스트 및 개선
```

 의 과정을 통해 기술을 이해하려고 노력하고 있습니다.

 특히 **컴퓨터과학, 정보보안, 정보관리**를 서로 분리된 영역으로 보기보다는\
 하나의 정보 시스템을 구성하는 서로 연결된 분야로 바라보고 있습니다.
