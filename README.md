### 공개 프로필이라면 개인정보 부분은 이렇게 하는 것도 좋아

GitHub는 공개 페이지이기 때문에 **거주지와 생년월일을 반드시 상세하게 공개할 필요는 없어.** 예를 들어:

```markdown
## Profile

| 항목 | 내용 |
|---|---|
| 이름 | [이름] |
| 전공 | AISW학과 |
| 소속 | [대학교] |
| 거주 지역 | [경기도 / 서울 등] |
| 출생연도 | [200X년] |
| 이메일 | [이메일] |
````

 이렇게 **`YYYY.MM.DD` 대신 출생연도만**, **상세 주소 대신 시·도 정도**로 작성하면 자기소개에는 충분하면서 개인정보 노출은 줄일 수 있어.

 또한 GitHub 대문은 너무 많은 정보를 한꺼번에 넣기보다는 **상단에서 `이름 → AISW학 → 관심 분야 → 현재 하는 일`이 바로 보이게 하는 것**이 중요해. 이후 `Projects`, `Skills`, `Education`을 배치하면 기술 포트폴리오로도 자연스럽게 이어져.
